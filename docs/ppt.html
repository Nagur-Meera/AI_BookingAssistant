📚 RAG Pipeline Design

📄 PDF Upload
Multiple files
→
📝 Text Extraction
PyPDFLoader
→
✂️ Chunking
800 chars, 100 overlap
→
🔢 Embedding
text-embedding-3-small
→
🗃️ FAISS Store
Vector DB

📥 Ingestion Process

1. User uploads PDF(s) via UI
2. PyPDFLoader extracts text
3. RecursiveCharacterTextSplitter chunks
- chunk_size: 800
- chunk_overlap: 100
4. OpenAI embeddings generated
5. FAISS vector store created

🔍 Query Process

1. User asks question
2. Query embedded
3. Similarity search (k=3)
4. Context injected into prompt
5. LLM generates answer
6. Response returned to user

🎯 Challenges & Future Improvements

⚠️ Challenges Faced

  • LangChain Version: Import paths changed in newer versions - fixed with langchain-text-splitters
  • Secret Management: GitHub push protection blocked API keys - used .gitignore
  • State Management: Streamlit reruns on each interaction - used session_state
  • SQLite Persistence: Resets on Streamlit Cloud restart - acceptable for demo

🚀 Future Improvements

  • Supabase: Replace SQLite for persistent storage
  • Voice Input: Add STT for accessibility
  • Calendar Integration: Google Calendar sync
  • SMS Notifications: Twilio integration
  • Multi-language: i18n support
  • Analytics: Booking trends dashboard

💡 Lessons Learned

  • Always pin dependency versions
  • Use secrets management from start
  • Test on cloud early and often
  • Modular design enables faster debugging
